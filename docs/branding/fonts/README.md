# Schrift: Space Grotesk

Space Grotesk von Florian Karsten, lizenziert unter der SIL Open Font License 1.1
(https://openfontlicense.org). Die Lizenz erlaubt Nutzung, Einbettung und Weitergabe,
auch kommerziell; die Schrift selbst darf nicht einzeln verkauft werden.

- `SpaceGrotesk-VariableFont_wght.ttf` – Original (variable, Gewicht 300–700)
- `SpaceGrotesk-SemiBold.ttf` (600) – Wortmarke „open-ora“
- `SpaceGrotesk-Medium.ttf` (500) – Unterzeile und Domain

Die beiden festen Schnitte sind mit fontTools aus der variablen Datei erzeugt
(`fontTools.varLib.instancer`).
